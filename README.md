# AI Code Reviewer

AI Code Reviewer is an AI-powered web application that analyzes code, identifies bugs, suggests fixes, and explains code to help developers understand and improve their programs.

## Features

* AI-powered code review
* Bug and error detection
* Code improvement suggestions
* Code explanation
* Simple and responsive interface

## Tech Stack

Frontend: React.js
Backend: Node.js, Express.js
AI: Groq API
Deployment: Vercel

## Run Locally

```bash
git clone https://github.com/GarvAhuja408/AI-Code-reviewer.git
cd AI-Code-reviewer
```

Install dependencies:

```bash
cd backend
npm install

cd ../frontend
npm install
```

Start the backend and frontend separately.
